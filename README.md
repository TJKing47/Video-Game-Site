# 🎮 Video Game Review Site

A simple and clean web-based platform for browsing and writing video game reviews. Built as a personal project to explore frontend development and practice UI layout and interactivity.

## 📋 Features

- View placeholder reviews for video games
- Static content layout with clean design
- Built with core web technologies (no frameworks)

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
